# SOFTENG 283 — A3

Implement this user story with TDD

As a registered user I want to set or change my account password so that I can secure my account.

Acceptance Criteria
- Password length must be 8–20 characters.
- Must contain ≥1 uppercase, ≥1 lowercase, ≥1 digit, ≥1 special character (!@#$%^&*).
- Password cannot contain the username (case-insensitive).
- Service must hash the password and store it through a repository.
- On any rule violation, the system report the problem.

Use TDD, Mockito, Junit, as discussed in class.
